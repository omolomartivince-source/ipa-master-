# IPA Master

**English IPA Transcription & Phonetics Learning App** for Android.

## About
IPA Master helps users learn the International Phonetic Alphabet (IPA), practice English pronunciation, and convert text to IPA transcription.

## Features (V1)
- Interactive IPA Chart
- Text → IPA Converter
- Audio pronunciation for symbols
- Learning / Practice mode

## Project Structure
The Android source code is inside the file:
`IPA_MASTER_Android_V1_project.zip`

## How to open the project
1. Download the zip file
2. Extract it
3. Open the extracted folder with **Android Studio**
